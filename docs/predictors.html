EVD Outcome Modeling and Predictor Analysis

Contents

  • Method
  • Independent Predictors of EVD Outcome and Complications
  • Global Multivariable Model of EVD Outcomes


We conducted a comprehensive analysis to identify predictors of Ebola Virus Disease (EVD) outcomes and complications.
A stepwise modeling workflow was applied, including data cleaning, univariate screening, collinearity assessment, LASSO selection, and multivariable regression, to ensure robust predictor identification.
To enhance interpretability and model power, clinically overlapping symptoms were grouped into coherent categories.

Receiver Operating Characteristic (ROC) analyses were used to determine optimal cycle threshold (Ct) values for predicting outcomes.
Independent predictors were quantified using Poisson regression with robust standard errors (adjusted risk ratios, aRR) and logistic regression (odds ratios, OR), with results presented for death, treatment subgroups, and key complications.

The following sections present detailed outputs, including:
- Symptom grouping tables for enhanced interpretability,
- ROC curves and threshold analyses,
- Multivariable Poisson regression panels for death and complications,
- Global multivariable logistic regression tables and forest plots combining all selected predictors.

ROC Analysis

Next, Receiver Operating Characteristic (ROC) analyses were performed to determine the optimal cycle threshold (Ct) value for predicting participant outcomes.
With an area under the curve (AUC) of 0.85, ROC analysis identified a Ct cut-off of 23.25 as the optimal threshold to discriminate outcomes, achieving a sensitivity of 79% and a specificity of 77%.

Stepwise Approach to Modeling Outcomes and Complications

We implemented a structured, stepwise modeling workflow (3) to identify independent predictors of clinical outcomes and complications.

Data cleaning and wrangling — All datasets were harmonized and inspected for inconsistencies, missing values, and implausible entries using the tidyverse R packages (Wickham et al. 2019).

Univariate screening — Each predictor was first evaluated in a univariate logistic regression model. Variables with sparse categories or those causing quasi-complete separation were excluded.

Collinearity assessment — Remaining variables were tested for multicollinearity using the car package and Variance Inflation Factor (GVIF) metrics (Fox and Weisberg 2019). Predictors with generalized VIF (GVIFscaled) values ≤ 1.68 were retained.

LASSO regression — To refine the model, Least Absolute Shrinkage and Selection Operator (LASSO) regression was applied using the glmnet package (J. Friedman and Tibshirani 2021), shrinking weak predictors and retaining the strongest associations.

Multivariable logistic regression — Predictors selected by LASSO were entered into multivariable logistic regression models to estimate adjusted odds ratios (OR) with 95% confidence intervals.

Computation of risk ratios — For interpretability, adjusted risk ratios (RR) were derived from robust Poisson regression models using the sandwich and lmtest packages (Zeileis 2020; Hothorn and Zeileis 2020). Raw (unadjusted) RRs were also calculated for binary predictors.

All analyses were conducted in R version 4.4.1 (R Core Team 2023). This stepwise approach ensured model parsimony, minimized overfitting, and enhanced interpretability.

Independent Predictors of EVD Outcome and Complications

Adjusted risk ratios (aRR) and 95% confidence intervals were estimated using multivariable Poisson regression with robust standard errors. Predictors for each outcome and complication were selected based on the stepwise modeling workflow described above.

The resulting aRRs are displayed in interactive panels for different outcomes: death, death among treated patients, and complications including renal failure and bleeding. Each table presents the adjusted risk ratio and 95% confidence interval for all non-intercept predictors.

Analyses were implemented in R using the glm() function with a log link, robust standard errors from the sandwich package, and exponentiated coefficients to obtain interpretable risk ratios.

Global Multivariable Model of EVD Outcomes

To provide an integrated view of all predictors, we fitted a global multivariable logistic regression model using all selected variables (glm() with binomial family). Adjusted odds ratios (OR) and 95% confidence intervals were computed from exponentiated coefficients, while adjusted risk ratios (aRR) and raw RRs were also derived using robust standard errors from the sandwich package.

The final table presents:
- Adjusted ORs with 95% CI
- Adjusted RRs with 95% CI
- Raw (unadjusted) RRs
- Significance indicators (***, **, *, .)
- Direction of association (⬆ for positive, ⬇ for negative)

A forest plot was added to visualize effect sizes on the log scale, with point estimates and confidence intervals clearly annotated. This combined approach allows for a comprehensive assessment of the independent contribution of each predictor while maintaining interpretability across different measures of association.
